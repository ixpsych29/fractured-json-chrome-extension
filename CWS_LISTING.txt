LONG DESCRIPTION
────────────────────────────────────────
Fractured JSON — Formatter automatically detects raw JSON on any page and transforms it into a beautifully formatted, syntax-highlighted interactive viewer.

⚡ Smart FracturedJson Alignment
This isn't just another pretty-printer. The FracturedJson algorithm intelligently aligns related values into readable columns — short arrays stay on one line, related keys line up vertically, and deeply nested structures expand with perfectly consistent indentation. The result is JSON that's actually easy to scan and understand.

🌗 Dark Mode & Themes
Three polished themes — Dark, Light, and Cobalt — with carefully tuned token colours for keys, strings, numbers, booleans, and punctuation. Your preference is remembered across sessions.

🔒 Works on Strict-CSP Pages
Many API endpoints (like api.github.com) enforce strict Content-Security-Policy headers that break other formatters. This extension handles those pages seamlessly by routing formatting through a background service worker — so it works everywhere, even on locked-down API responses that return "default-src 'none'".

🖥️ Clean UI
Formatted JSON is displayed inside an elegant browser-window frame with macOS-style traffic lights, an address bar showing the current URL, and a sticky toolbar. It looks and feels native.

📌 Features
• Three format modes: Pretty-print, Minify, and Near-minify
• Toggleable line numbers with a clean gutter
• One-click toggle between formatted and raw view
• Download formatted JSON as a .json file
• Worker-based formatting — large payloads never freeze the browser
• Automatic detection of Chrome's built-in JSON viewer
• Persistent preferences across tabs and sessions

🛡️ Privacy-First
All processing happens locally in your browser. Zero data is collected, stored, or transmitted to external servers. See our full privacy policy for details.

HOW TO USE
1. Install the extension.
2. Navigate to any URL that returns raw JSON — the viewer activates automatically.
   Try these:
   • https://dummyjson.com/products
   • https://jsonplaceholder.typicode.com/users
   • https://api.github.com/users  (strict-CSP — works!)
3. Use the toolbar to switch modes, toggle line numbers, or change themes.
4. Click "View raw" or "Download" any time.

No setup, no configuration — it just works.
